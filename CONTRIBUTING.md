# Contributing

Gracias por tu interés en CallMind AI. Para contribuir o evaluar el proyecto localmente:

1. Clona el repositorio.
2. Crea un entorno virtual Python 3.11+.
3. Instala dependencias: `pip install -r requirements.txt`.
4. Ejecuta la app: `python run.py`.

Para publicar la rama `main` en GitHub Pages, el workflow `.github/workflows/deploy_pages.yml` despliega `app/static`.
